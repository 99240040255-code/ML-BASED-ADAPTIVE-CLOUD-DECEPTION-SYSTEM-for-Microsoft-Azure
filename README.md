ML-Based Adaptive Cloud Deception System for Microsoft Azure


An intelligent, machine-learning-driven cyber deception framework designed for Microsoft Azure. This system dynamically deploys, alters, and manages honeypots, honeytokens, and decoy infrastructure based on real-time threat intelligence and attacker behavior analysis.
Unlike static honeypots, this system uses Reinforcement Learning (RL) and Anomaly Detection to adapt defenses actively, wasting attacker resources and gathering high-fidelity threat intelligence without risking production environments.
